1. Deploy su Cloudflare Workers + Neon PostgreSQL

Il progetto include wrangler.toml, worker.js e .assetsignore preconfigurati per Cloudflare Workers.

  1. 1. Crea il Database PostgreSQL gratuito su Neon.tech

    Vai su neon.tech, crea un progetto gratuito permanente e copia la stringa di connessione postgresql://... che userai come DATABASE_URL.

  2. 2. Collega il Repository su Cloudflare Dashboard

    Accedi a dash.cloudflare.com, apri Workers & Pages → Create → Workers → Import a repository, seleziona il tuo repository GitHub e lascia il comando di deploy predefinito npx wrangler deploy.

  3. 3. Inserisci le Variabili d'Ambiente su Cloudflare

    Nel tuo Worker su Cloudflare vai in Settings → Variables and Secrets e aggiungi:

    DATABASE_URL La stringa PostgreSQL di Neon.tech (salva automazioni, decisioni timeline, log e token per sempre)
    META_ACCESS_TOKEN Il tuo System User Token o Long-Lived Token di Meta Ads
    PUBBLIE_API_KEY La chiave API di Pubblie (opzionale, salvabile anche dalla dashboard)
    CRON_SECRET Una password segreta a tua scelta (es. mio_segreto_2025) per proteggere l'endpoint cron
    APP_PASSWORD Opzionale: imposta la Master Password (default preconfigurato: Salernitana:86)

2. Esecuzione Automatica Ogni Giorno alle 18:00

Il file wrangler.toml attiva in automatico il Cron Trigger nativo di Cloudflare ogni giorno alle ore 18:00 (ora italiana).

Cron Trigger Nativo Cloudflare: Ogni giorno alle 18:00 ora italiana (0 16,17 * * *)
Metodo HTTP (per cron esterno): POST (oppure GET)

Nuova Regola di Automazione

1. Sorgente dei Post da Monitorare (Solo Formato POST)
Se compilato, sponsorizza solo i post che contengono almeno una di queste parole.
Se un post contiene una di queste parole o hashtag, verra saltato.
2. Destinazione su Meta Ads
Meta consente massimo 50 inserzioni per ogni Gruppo di Inserzioni.
Scegli quale AdSet della campagna copiare (budget, target, posizionamenti).
Variabili: {adset} (nome originale), {date} (data creazione). Creato sempre ATTIVO.
3. Pianificazione e Parametri Inserzione
Protezione Non-Retroattiva: i post pubblicati prima di questa data verranno ignorati.
Variabili: {platform}, {post}, {date}, {id}
Obbligatorio se la campagna ha obiettivo Traffico / Click sul link (evita errore Meta #1443128).
